# Verificare mobilă — captură rapidă

Aplicația locală pornește și se hidratează corect în browser la `http://localhost:3000/`. Ecranul Astăzi este randat, iar onboarding-ul este vizibil în starea inițială fără date. Consola browserului nu a raportat erori de runtime. Următoarea verificare trebuie să deschidă acțiunea „Înregistrează mișcare” după închiderea onboarding-ului și să confirme vizual foaia mobilă cu suma dominantă, categorii recente și butonul persistent de salvare.

Data verificării: 5 septembrie 2026.

Onboarding-ul a trecut din turul introductiv în configurarea familiei după apăsarea controlată a acțiunii „Sari peste”, fără erori de runtime. Pentru testarea capturii rapide este necesară închiderea configurării prin „Mai târziu” sau completarea pașilor.

După închiderea configurării, ecranul Astăzi apare corect cu acțiunea principală „Înregistrează mișcare” vizibilă și cu hero-ul „Plicuri neconfigurate”. Layout-ul responsive se încarcă fără eroare; urmează testarea foii de captură.

Formularul „Înregistrare rapidă” a fost deschis fără erori. La 125,50 RON, suma este afișată dominant și lizibil, iar mesajul de sold insuficient este vizibil. Butonul „Salvează acum” rămâne fixat vizual la baza foii, iar câmpurile secundare sunt stivuite pentru mobil.
