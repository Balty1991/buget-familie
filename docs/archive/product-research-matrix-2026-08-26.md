# Matrice de cercetare pentru Buget Familie

## Domenii investigate

| Domeniu | Întrebarea decisivă | Rezultat aplicabil |
|---|---|---|
| Buget familial | Cum văd membrii aceiași bani fără a pierde responsabilitatea personală? | Vederi comune, membru/sursă la fiecare mișcare, alocări verificabile. |
| Planificare | Cum se rezervă bani înainte de cheltuială, nu doar se raportează după? | Plan până la salariu, plicuri/alocări, scadențe rezervate. |
| Jurnal și bonuri | Cum se înregistrează o cheltuială rapid și corect de pe telefon? | Formular cu un singur ecran, sumă, membru, sursă, categorie și bon opțional. |
| Asistent | Ce semnale reduc stresul și duc la o acțiune reală? | Ritm de cheltuire, praguri, scadențe, obiective și explicații cu datele sursă. |
| Colaborare | Cum se sincronizează fără expunerea datelor familiei? | Copie criptată explicită în repo privat, fără token salvat permanent. |
| Mobile/Android | Ce este obligatoriu pentru folosire zilnică? | Icon adaptiv, ținte tactile, offline, permisiuni cerute contextual, APK repetabil. |
| Accesibilitate | Cum rămâne utilizabilă la mână, contrast și focus? | Reflow, text lizibil, controale mari, focus vizibil și mesaje clare. |

## Criterii de prioritate

O funcție este prioritizată când reduce pașii unei acțiuni zilnice, folosește datele existente fără duplicare, explică impactul financiar și nu expune datele familiei. Conectările bancare, deciziile financiare personalizate și AI extern rămân în afara variantei GitHub Pages până există o arhitectură securizată și un consimțământ explicit.
