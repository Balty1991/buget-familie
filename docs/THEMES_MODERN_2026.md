## Cum arată fiecare temă

| Temă | Look |
|------|------|
| **white / ink** | Hârtie platinum calmă (`#e8ece9` → `#fafbfa`), accent pin `#176b54`, fără violet murdar |
| **dark** | Graphite OLED (`#0c0d0f`), primary gri moale `#b8bec8`, fără glow |
| **aurora** | Personalitate păstrată, bloom violet redus; mint `#65d3a6` rămâne primary |
| **navy** | Albastru adânc `#080e1a`, accent aur `#d4b06a`, fără glow ieftin |
| **cyber** | Mint neon `#7cffc4` pe near-black, controlat — zero purple extra |

Shared: `--cf-glow: transparent`, umbre ink/alpha, card pad 20–24px, CTA filled, tab-uri fill active, dock clearance, mobil ≤640 sans (Outfit).
